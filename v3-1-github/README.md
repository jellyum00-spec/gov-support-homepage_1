- `gov-support-v3-1.html`

## GitHub 업로드 위치

GitHub 저장소 최상위에 아래 구조 그대로 업로드하면 됩니다.

```text
gov-support-v3-1.html
assets/
  odd-street.jpg
  blacklabel.jpg
```

## Vercel에서 확인

저장소가 Vercel에 연결되어 있다면 배포 후 아래 주소로 접근합니다.

```text
https://프로젝트주소.vercel.app/gov-support-v3-1.html
```

## 다른 노트북에서 수정

1. GitHub 저장소를 열거나 내려받습니다.
2. `gov-support-v3-1.html`을 수정합니다.
3. 이미지 경로는 `assets/odd-street.jpg`, `assets/blacklabel.jpg` 그대로 유지합니다.
4. GitHub에 저장하면 Vercel이 자동 배포합니다.
